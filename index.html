Add one source and access multiple Kodi repositories in one place. Your complete entertainment hub.

How It Works

1

Open Kodi File Manager

Launch Kodi and navigate to the File Manager to add a new source.

2

Add the Source URL

Copy one of the repository URLs from below and add it as a new source in Kodi.

3

Install from ZIP

Go to Install from ZIP file and select the repository to install.

4

Browse Repositories

Once installed, browse and install any addon from the available repositories.
